# 交付验收清单

知华科技（上海如静知华信息科技有限公司）｜[官网](https://www.zhuatech.cn/)｜商业授权、定制与集成咨询微信：`zhuatech`、`zhuatech2`

本清单用于门店试用与后续商用交付评审，不把自动化测试等同于真实门店验收。

| 项目 | 验收动作 | 本仓库状态 |
| --- | --- | --- |
| 安装 | 全新 Node 24.19+ 环境或 Docker Compose 启动，首次自设管理员密码 | 待独立机器复验 |
| 基础业务 | 从空库录入分类、菜品和桌台，堂食开台、未送厨数量/备注编辑、送厨、出餐、结账与小票；补测换桌、外带、退菜、拆单、折扣 | 自动化覆盖金额、票据和拆单后厨归属；浏览器实测从空库配置到现金结账通过 |
| 收款 | 现金、找零、重复结账、外部终端收款及退款人工登记、现金退款 | 自动化覆盖现金、幂等和终端交易号；浏览器实测终端收款及退款登记；外部支付渠道未集成 |
| 权限 | 账号、角色、停用和自助改密；收银员不能调折扣与退款；后厨不能查看订单、菜单价格和报表 | 接口自动化覆盖角色隔离、停用及改密后会话失效；现场员工权限仍需复验 |
| 交班与报表 | 两名收银员共用同一钱箱，分别收款与退款；开班人/店长交班、未结订单跨班提示、备用金、现金存取、跨班退款、差额、班次历史与日报 | 自动化覆盖多人共用现金账、操作人、未结订单确认及清点期间数据变化拦截；真实门店对账待验证 |
| 并发订单 | 两个会话同时看同一订单，一人加菜或结账后另一人提交旧金额 | 接口自动化覆盖旧版本拒绝、重新读取及重复结账幂等；页面逻辑测试覆盖延迟响应不覆盖新选择、确认窗口保留原版本及无变化不重绘；浏览器实测另一账号改菜后自动更新、确认期间改价后拒绝旧金额；现场网络仍需复验 |
| 数据 | 关闭服务、重启、备份、恢复、完整性检查 | 自动化覆盖重启持久化、营业中备份、在独立路径恢复并继续营业；原位恢复及断电演练待做 |
| 设备与渠道 | 票据打印机、钱箱、扫码枪、聚合支付、外卖与发票 | 不在当前实现范围；需现场设备和商户接口权限 |
| 实际门店 | 高峰并发、网络/断电恢复、真实对账、员工培训 | 未有外部门店使用证据 |

浏览器已验证未勾选未结订单核对无法交班、清点期间现金变化会拒绝提交、核对后正常交班且订单保留。电脑（1366 像素）、平板（844 像素）和手机（390 像素）界面已检查并保留实际截图；手机确认窗口无页面横向溢出。

正式商用交付需根据签约范围完成门店现场测试、问题关闭、设备清单、备份恢复演练、操作培训与双方验收记录。
